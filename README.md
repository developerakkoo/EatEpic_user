# food_app

EatEpic customer Flutter app.

## Banner redirect links

Admin banners use a free-form `redirectLink` field. Supported patterns:

| Link | Action |
|------|--------|
| `https://...` | Open in browser |
| `/subscriptions`, `/search`, `/notifications`, `/account` | Switch bottom tab |
| `/cart`, `/orders`, `/support` | Push named route |
| `/category/{id}` | Open category kitchens screen |
| `/kitchen/{id}` | Open kitchen detail |
| `/home#categories` | Scroll to categories + highlight section |
| `/home#category/{id}` | Scroll to categories + highlight chip |
| `/home#top-kitchens`, `/home#meal-nearby` | Scroll to section |
